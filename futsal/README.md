# Footsal Owner Dashboard

Dashboard for footsal owners to manage their facilities and bookings.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:3003`

## Features

- Facility Profile Management
- Booking Management
- Pitch Management
- Revenue Analytics
- Settings & Configuration

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React Icons
- Date-fns
